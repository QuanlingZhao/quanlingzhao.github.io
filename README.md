# Quanling Zhao — Academic Homepage

This site uses the **actual [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme** through GitHub Pages' `remote_theme` support.

## What is already populated

- UC San Diego affiliation and research statement
- Research interests
- Selected research projects
- Recent news
- Full publication list
- Invited talks
- Mentoring
- Professional service
- Current CV PDF
- Google Scholar, GitHub, and LinkedIn links

## Before publishing

1. Optionally add a headshot as `assets/img/avatar.jpg`.
2. If you add a headshot, uncomment the `avatar:` line in `_config.yml`.
3. Review the project descriptions and publication links.
4. If you deploy under a project repository rather than `QuanlingZhao.github.io`, update `canonical:` in `_config.yml`.

See `DEPLOYMENT.md` for deployment instructions.
